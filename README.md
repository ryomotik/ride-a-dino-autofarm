# 🦕 Ride A Dino! — Advanced Autofarm Bot

Продвинутый скрипт автоматизации для игры **[Ride A Dino!](https://www.roblox.com/games/93523763376122)** с красивым интерфейсом в стиле macOS (**Maclib UI**).

---

## ⚡ Возможности

- 🏋️ **Авто-тренировка хвата (Auto Grip Train)**: авто-посадка на личный тренажер и непрерывная тренировка хвата с авто-возвратом при падении или респавне.
- 🏡 **Авто-прокачка загона (Auto Pen Upgrade)**: автоматическая покупка улучшений загона при накоплении средств для расширения слотов динозавров и взрывного роста пассивного дохода ($/сек).
- 🦾 **Авто-покупка новых тренажеров (Auto Machine Tier)**: авто-покупка следующих тиров тренажеров (Triceratops, Dilophosaurus и т.д.) по мере накопления монет.
- ✨ **Авто-покупка и экипировка аур (Auto Aura Multiplier)**: автоматическое посещение магазина аур для покупки и экипировки наивысшей доступной ауры (увеличение прироста хвата до x2.5 – x4.5!).
- 🎁 **Авто-сбор наград (Auto Rewards)**: автоматический сбор оффлайн-наград и бесплатных подарков каждые 30 секунд.
- 🛡️ **Anti-AFK**: защита от стандартного отключения Roblox за 20 минут неактивности.

---

## 🎮 Управление UI

- **Горячая клавиша**: `Right Control` — скрыть / показать окно настроек.
- Переключатели для всех функций автоматизации.
- Быстрые кнопки мгновенных действий (телепорт на тренажер, спешивание, ручной апгрейд загона/машины).
- Вкладка со статистикой в реальном времени.

---

## 🚀 Запуск скрипта

Вставьте код из файла `autofarm.luau` в ваш инжектор/экзекутор (Real, Wave, Solara, Swift, Hydrogen и др.) и нажмите Execute.
